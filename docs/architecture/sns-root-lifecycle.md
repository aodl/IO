# SNS root lifecycle

SNS governance/root controls later dapp upgrades, including pause/drain/config-change workflows. Narrow value-moving update methods authenticate their own caller and canonical effects; root control does not grant an assertion-based completion method.

Local proposal/root tests are mock/PocketIC only control-plane evidence. No mainnet upgrade or production activation occurs in this tranche.

That harness does not run the official SNS launch or decentralization swap flow and does not call mainnet. It records an approved upgrade intent, then the test harness executes the PocketIC upgrade against the artifact named in `release-artifacts/manifest.json`. Production SNS root/governance wiring remains future work.
