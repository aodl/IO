# Pre-simplification research (historical)

Files in this directory preserve design research from before IO's simplified
execution architecture. They are non-normative and must not be used as current
protocol, API, production-wiring, deployment, or launch instructions.

Start with the repository [README](../../../README.md), current component
READMEs, accepted architecture decisions under `docs/architecture/`, and the
machine-checked readiness and release sources linked there. When a historical
document conflicts with implementation, production Candid, checked-in
configuration, tests, or executable tooling, those current sources prevail.

This research remains useful for understanding alternatives that were
considered and deliberately removed. Reintroducing a superseded monetary path
requires demonstrated need and an explicit architecture decision; historical
presence is not justification by itself.
