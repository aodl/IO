# Prelaunch configuration validation

Install arguments are validated against the actual canister principal. The value-moving Stream and NNS Manager canisters install `Paused`; the Historian uses optional observation configuration and the frontend initializes certified assets without that monetary lifecycle. Governance unpause performs the applicable canonical fee, supported-standard, supply/exclusion, staging-balance, and protected-identity preflight checks.

Checked-in mainnet install-argument files are deliberately non-runnable TODO templates. ProductionActive is unavailable. A later explicitly approved audit must verify that reserved canisters contain no value-bearing state before any clean install decision.
